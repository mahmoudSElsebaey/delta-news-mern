# دليل استخدام منصة دلتا نيوز (Delta News)

**منصة إخبارية ورياضية متعددة اللغات (SaaS) مبنية بـ MERN**

---

## 1. نظرة عامة وهدف الموقع

**Delta News / دلتا نيوز** منصة إعلامية حديثة متخصصة في الأخبار والرياضة، تدعم العربية والإنجليزية بالكامل مع واجهة عامة احترافية ولوحة تحكم تحريرية قوية.

### الهدف:
- تقديم محتوى إخباري ورياضي عالي الجودة بواجهة حديثة.
- دعم كامل للغتين مع SEO متقدم.
- لوحة تحكم للإدارة والتحرير مع أدوار متعددة.
- تجربة قراءة سلسة على كل الأجهزة.

---

## 2. الأدوار والصلاحيات

| الدور | الوصف | الصلاحيات |
|-------|--------|-----------|
| **الزائر** | قارئ عادي | تصفح الأخبار، البحث، القراءة |
| **المستخدم المسجل** | قارئ مسجل | + الإشارات المرجعية (Bookmarks) |
| **Editor** | محرر | كتابة ونشر المقالات، إدارة التصنيفات |
| **Admin** | مدير | كل الصلاحيات + إدارة المستخدمين والأدوار والإحصائيات |

### حسابات تجريبية

| الدور | البريد | كلمة المرور |
|-------|--------|-------------|
| Admin | admin@delta.news | Admin123! |
| Editor | editor@delta.news | Editor123! |

---

## 3. دورة القارئ (Customer Journey)

1. الدخول للصفحة الرئيسية → أخبار عاجلة + تريندينج + تصنيفات.
2. تصفح حسب التصنيف أو البحث.
3. قراءة المقال (عربي أو إنجليزي).
4. (اختياري) تسجيل الدخول وحفظ المقالات في المفضلة.
5. مشاركة المقالات.

---

## 4. دورة المحرر / الأدمن

1. تسجيل الدخول للوحة التحكم.
2. كتابة مقال جديد (محرر متعدد اللغات).
3. اختيار التصنيف والصور والـ SEO.
4. نشر أو حفظ كمسودة.
5. إدارة التصنيفات والمقالات السابقة.
6. (للأدمن) إدارة المستخدمين والأدوار وعرض التحليلات.

---

## 5. الميزات الرئيسية

- موقع عام تحريري (Hero, Breaking Ticker, Trending, Categories).
- عربي / إنجليزي كامل مع مسارات `/ar` و `/en`.
- SEO متقدم: canonical, hreflang, Open Graph, JSON-LD, Sitemap, Robots.
- لوحة تحكم Admin (مقالات، تصنيفات، تحليلات، أدوار).
- محرر مقالات متعدد اللغات.
- JWT Auth (httpOnly cookies) + Role-based Access.
- Bookmarks API.
- Rate Limiting + Helmet + Zod Validation.

---

## 6. التقنيات

- **Frontend:** React 19 + TypeScript + Tailwind CSS
- **Backend:** Node.js + Express + MongoDB
- **Auth:** JWT + httpOnly cookies
- **i18n:** كامل مع RTL/LTR
